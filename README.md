### 👋 En deux lignes

Je sécurise des infrastructures et je construis les applications qui tournent dessus.
Mon travail va du durcissement d'un pare-feu à la rédaction d'une politique de sécurité,
en passant par le code d'une API et l'entraînement d'un modèle de détection. Ce qui m'intéresse
dans la cybersécurité, c'est le moment où une alerte technique devient une décision que
quelqu'un peut prendre.
